# Engineering with AI: Beyond Vibe Coding

An English technical-book project comparing BMAD Method, GSD's framework lineage, AWS AI-DLC and AI Unified Process, with Spec-Driven Development as a cross-cutting approach. The author supplied [fourteen chapter titles and their order](OUTLINE.md), which are preserved.

## Book and prepared publication files

The book's author manuscript and targeted AI publication-preparation pass are complete for edition 1.1. It contains **66,497 chapter words**, fourteen chapters and 95 planned sections.

Download the [publication package](output/engineering-with-ai-publication.zip), [EPUB](output/publication/engineering-with-ai.epub), [6 x 9 paperback interior](output/pdf/engineering-with-ai-print.pdf), and [full paperback cover](output/publication/engineering-with-ai-paperback-cover.pdf).

Read the [complete manuscript](manuscript/REVIEW_MANUSCRIPT.md) or the [typeset PDF](output/pdf/engineering-with-ai.pdf). The [manuscript report](research/MANUSCRIPT_REPORT.md) records counts, evidence scope and the independent/publication reviews that remain pending.

The [TypeScript policy model](examples/approval-policy/README.md) has ten passing local sequential checks. The book's full case is a qualitative walkthrough.

The evidence base is in the [M2 report](research/M2_REPORT.md), [four method dossiers and comparison](research/COMPARISON_EVIDENCE.md), and [claim index](research/CLAIM_REGISTER.md). The architecture accepted in A06 is summarized in the [M1 report](research/M1_REPORT.md): fourteen chapters, practicing-engineer/lead/architect audience, 66,500-word main text and a vendor-access approval SaaS case using **TypeScript / Node.js**. Exact framework, database, host/model and run versions remain open pending evidence and compatibility work.

## Boundaries

M1 is accepted planning; M2 is bounded research; M3 versions are preserved. A11 permits further reversible research/drafting/editing without repeated chapter permissions. Human gates are not passed by text preparation. A methodology/application trial needs the [run protocol](research/RUN_PROTOCOL.md) and [readiness gate](research/EXPERIMENT_READINESS.md). There is no fifth SDD arm, default endorsement, invented production history or authority to spend, deploy or publish.
