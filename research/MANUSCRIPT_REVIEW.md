## Substantive checks

- **Case consistency:** no self-approval with overlapping roles; current same-tenant eligibility; distinct high-risk v2 approvals; creation-time v1 binding; terminal consistency; durable tenant history. Interface/retry/disclosure/persistence details remain visibly unfrozen.
- **Fixture quality:** self-approval starts pending with otherwise sufficient roles; foreign-record probes require an existing record and positive control. This preserves the correction found in the earlier teaching draft.
- **Evidence distinction:** framework instructions, maintainer/field claims, authored walkthroughs and actual local checks retain different labels. No proposed check becomes a passing test in prose.
- **Tool boundary:** editors, coding hosts and adapters remain implementation context. Core versus similarly named product and AIUP core versus stack path remain explicit.
- **Narrative ownership:** C02 supplies proportionate practice, C03 the vocabulary, C04–C07 native mechanisms, C08 policy analysis, C09 evidence synthesis, C10 selection, C11 the full qualitative case and C12–C14 assurance/diagnosis/reevaluation.
- **Originality:** prose and teaching artifacts are composed for the book's own case. No external prompts, code collections, figures or book passages are reproduced. Public publisher metadata does not establish whole-book independence; lawful full-text review remains pending.
